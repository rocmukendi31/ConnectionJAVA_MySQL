# ConnectionJAVA_MySQL

This project demonstrates how to connect a Java application to a MySQL database using JDBC.

## Files

- `ProductDetails.java` - Handles product details operations with MySQL database
- `StudentRecords.java` - Handles student records operations with MySQL database

## Setup

1. Ensure you have MySQL installed and running
2. Create a database for the application
3. Update the database connection details in the Java files (URL, username, password)
4. Add the MySQL JDBC connector to your classpath

## Usage

Compile the Java files:
```bash
javac ProductDetails.java
javac StudentRecords.java
```

Run the applications:
```bash
java ProductDetails
java StudentRecords
```

## Requirements

- Java JDK 8 or higher
- MySQL Database
- MySQL JDBC Driver (Connector/J)
